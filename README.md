Landing Page - Consultório de Psicologia

Desenvolvido por: João Victor de Carvalho

📖 Descrição do Projeto

Esta é uma landing page responsiva desenvolvida para um consultório de psicologia e psicoterapia. O objetivo da aplicação é apresentar os serviços oferecidos, exibir horários de funcionamento, mostrar feedbacks de pacientes e facilitar o contato e localização.

O layout foi construído com alta fidelidade a um design pré-estabelecido no Figma.

🚀 Como rodar o projeto localmente

1. Clone o repositório:

git clone https://github.com/joao-victr/linked-ps-web-joao-victor-de-carvalho.git
cd linked-ps-web-joao-victor-de-carvalho


2. Instale as dependências e inicie o servidor:

npm install && npm start


4. Acesse no navegador:
Abra o link fornecido no terminal (geralmente http://localhost:5173/).

🛠 Tecnologias e Ferramentas Utilizadas

React: Biblioteca JavaScript para construção da interface de usuário baseada em componentes.

Vite: Ferramenta de build e servidor de desenvolvimento moderno.

HTML5 & CSS3: Semântica adequada e estilização nativa.


🧠 Decisões Técnicas Relevantes

Componentização e CSS Isolado: A aplicação foi dividida em componentes independentes (Header, Hero, Servicos, Feedbacks, etc.). Cada componente possui seu próprio arquivo .jsx e .css. Isso evita vazamento de estilos, mantém o App.jsx limpo como um mero orquestrador e facilita a manutenção.
